render-vps

Render par chalne wala Linux box — kisi bhi SSH client se connect karo
service live

1 Tunnel start karo (apne laptop par)

Render sirf HTTPS deta hai, raw SSH port nahi. Yeh script aapke machine par 127.0.0.1:2222 khol deta hai jo WebSocket se Render tak jata hai.

$ node client/tunnel.js \
    wss://{{HOST}}/ws?token=YOUR_WS_TOKEN 2222

Node 22+ hai to kuch install nahi chahiye. Warna: npm i ws. Python wala version bhi hai: python client/tunnel.py.

2 SSH connect karo

Tunnel chalne ke baad yeh normal SSH hai — OpenSSH, PuTTY, Termius, JuiceSSH, kuch bhi.

$ ssh -p 2222 {{USER}}@127.0.0.1
# password: SSH_PASSWORD (Render env me jo set kiya)

SFTP/SCP bhi chalega: sftp -P 2222 {{USER}}@127.0.0.1

Host
{{HOST}}
User
{{USER}}
Tunnel port
2222 (aapki machine par)

3 Browser se seedha shell (kuch install nahi)

Neeche WS_TOKEN daalo aur Connect dabao — browser me hi full terminal khul jayega.
